# Metroidvania Game

A 2D Metroidvania-style action RPG developed with Godot 4 as part of ACM @ UCSD Game Development.

## Overview

This project features:

- Component-based architecture for modular gameplay systems
- Character progression and RPG stat scaling
- Skill tree and weapon upgrade systems
- Multiple combat styles (melee, ranged, magic)
- Enemy AI and combat encounters
- Multi-level exploration and progression

## My Contributions

- Implemented gameplay systems including movement, combat, skill progression, and upgrades
- Developed modular scripts using a component-based architecture
- Designed and balanced RPG stat scaling across multiple upgrade tiers
- Participated in gameplay testing and balancing

## Controls

| Action | Key |
|----------|----------|
| Move | Q / W / E / R |
| Jump | Space |
| Attack | Left Mouse Button |
| Enter Next Level / Interact | Right Mouse Button |

## Running the Project

### Prerequisites

Install:

- Godot 4.x

### Clone the Repository

```bash
git clone https://github.com/acmucsd-projects/su24-gamedev-team-2.git
```

### Launch

1. Open Godot 4
2. Import the cloned project
3. Open the project
4. Click the ▶ Play button in the top-right corner

The game will launch directly from the Godot editor.

## Gameplay

Explore interconnected levels, defeat enemies, unlock upgrades, and progress through increasingly challenging encounters.
